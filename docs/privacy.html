Privacy

Last updated 2026-10-09.

Layer Herder is fully offline. It makes no network connections, does not check for updates, and collects no data. It does not transfer any information to other networked systems.

Settings and translation memory are stored only on your computer, in your user profile (%APPDATA%\AcLayerStandardizer). Uninstalling the program leaves these files in place unless you delete them.

The only outbound action is the Settings link to this website. It opens in your own browser when you click it, and Layer Herder itself does not send anything.

Questions about this policy: info@layerherd.com.
