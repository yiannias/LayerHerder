Layer Herder

Tidy your drawings. Herd your layers into shape.

Every drawing names its layers differently. Layer Herder maps them onto your standard and applies the changes in one pass, with undo.

The problem

Three drawings can name the same wall layer three ways: WALL, A WALLS and wall-exist. None of them match your standard. Fixing that by hand means renaming, merging and re-coloring layer by layer, drawing after drawing.

Before: drawing layers

  • WALL
  • A WALLS
  • wall-exist
  • TXT
  • Dim_Arch
→

After: your standard

  • A-WALL
  • A-WALL
  • A-WALL-EXST
  • A-ANNO-TEXT
  • A-ANNO-DIMS

Illustrative names only. Layer Herder works from the standard file you point it at.

How it works

Three steps, inside AutoCAD.

  1. Type HERD

    The mapping editor opens with the drawing's layers on one side and your standard on the other. Layer Herder can also be opened from its ribbon tab.

  2. Connect the layers

    Exact matches connect automatically. Layers it has mapped before connect from memory, and close names are suggested. Connect anything left by hand.

  3. Apply

    Layers are renamed or merged to match in one pass. Apply & Remember also saves your decisions for the next drawing.

Match types

Each connection line is colored by how it was made.

  • Exact: the names are identical. Connected automatically.
  • Memory: you mapped this layer on an earlier drawing.
  • Suggested: a close name match, gated by a confidence slider you control.
  • Manual: a connection you drew yourself.

What it does

Everything runs inside AutoCAD on your machine.

  • Learns across drawings

    Decisions saved with Apply & Remember are reused automatically on the next drawing. You can import and export the memory file from Settings.

  • Suggests matches for new names

    If your standard uses TEXT and a drawing uses TXT, it suggests the link even if you have never mapped it.

  • Filters and search

    Filter each side by match type, discipline or category, or type part of a name to narrow the list.

  • Undo and redo in the editor

    Ctrl+Z and Ctrl+Y undo and redo your connections while you work. Right-click any connection and choose Delete Connection.

  • Purges empty layers

    Highlight layers with no entities and purge them, after a confirmation.

  • Matches properties, not just names

    Optionally sync color, linetype and lineweight to the standard, and set elements to ByLayer.

  • Leaves xrefs alone

    Layers from externally referenced files are excluded, because they cannot be edited from the drawing.

  • Node or Column view

    Node mode draws the mapping as a graph: drag from a source layer to a standard layer, scroll to zoom and middle-drag to pan. Column mode shows both sides as scrollable lists and pairs layers by dragging one row onto another. Switch with the slider at the bottom of the window.

Get started

  1. Download and run the installer

    It detects your AutoCAD versions and installs the matching build for each.

    Download installer

  2. Open a drawing and type HERD

    Pick your standard file in Settings the first time you run it.

  3. Connect, apply, and let memory do the rest

    The more drawings you clean up, the fewer connections you need to draw.

Why this exists

This is a personal project. I built it to solve my own layer-cleanup headaches, not as a commercial product. It is free, and I am happy to share it with any AutoCAD user who has the same problem.

Privacy

Layer Herder is fully offline. It makes no network connections, does not check for updates, and collects no data. Settings and translation memory are stored only on your computer, in your user profile (%APPDATA%\AcLayerStandardizer).

The only outbound action is the Settings link to this website, which opens in your own browser when you click it.
